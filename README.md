# 🎵 T.DAY - Playlist Spotify Visual

Bem-vindo ao **T.DAY**! Um projeto web interativo que transforma sua playlist do Spotify em uma experiência visual única e personalizada.

## 📋 Sobre o Projeto

T.DAY é uma aplicação web que permite visualizar e gerenciar suas playlists do Spotify de forma intuitiva e visualmente atraente. Com uma interface moderna e responsiva, você pode explorar suas músicas favoritas de um jeito novo!

## ✨ Características

- 🎨 Interface visual moderna e intuitiva
- 📱 Totalmente responsivo (funciona em todos os dispositivos)
- 🎵 Integração com Spotify (em desenvolvimento)
- 🎯 Navegação simples e amigável
- ⚡ Carregamento rápido
- 🌐 Hospedado com GitHub Pages

## 🚀 Como Começar

### Requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexão com internet
- (Opcional) Conta Spotify

### Instalação Local

```bash
# Clone o repositório
git clone https://github.com/RAIOS1000/T.DAY.git

# Navegue até a pasta
cd T.DAY

# Abra o arquivo no navegador
open index.html
# ou no Linux
xdg-open index.html
# ou no Windows
start index.html
```

### Uso Online
Acesse diretamente: [T.DAY no GitHub](https://github.com/RAIOS1000/T.DAY)
